## What these boards say (use as art direction)

- **Web / portfolio:** big editorial type over generous whitespace; one loud accent color (Klein blue, red, acid green) on black or white;
  3D character self-portraits ("Hi, I'm …"); dark bento dashboards; pixel/wireframe display type; playful 3D objects (stamps, signs, toys).
  → Editorial world + the hero for every world: **one huge word, one accent, one 3D object of you.**
- **Type:** liquid chrome, inflated/puffy 3D letters, retro serifs, grunge streetwear poster type, **Devanagari display lettering**,
  title-card typography from music videos. → Machine logo in chrome; Album Rollout title cards; Hindi wordmark as a signature.
- **Prompts:** material studies (chrome, fur, leather patch, embroidery, liquid glass, clouds) for letters/logos.
  → Generate your own hero letters / world icons in these materials so the art is yours, not borrowed.
- **Intro text pattern:** "welcome to my portfolio" in script + grotesk pairing, "Hi, I'm …" over a character, "CREATIVE · DEVELOPER" stacked caps.
